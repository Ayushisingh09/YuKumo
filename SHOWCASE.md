## 📝 How to Add Your Project

Want to list your project here? We welcome all open-source and public Discord music bots using Yukumo!

### Step 1: Fork & Edit
Fork the repository and add your project to the table above in `SHOWCASE.md` using this format:

```markdown
| **Your Bot Name** | Short description of your bot. | Framework (e.g. discord.js, Eris, Seyfert) | [Website/Invite](https://yourbot.com) \| [Source](https://github.com/username/repo) |
```

### Step 2: Open a Pull Request
Submit a Pull Request titled `docs: add [Bot Name] to SHOWCASE.md`. Once reviewed, your bot will be listed!
